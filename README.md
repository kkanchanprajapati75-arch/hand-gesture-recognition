# Hand Gesture Recognition Using OpenCV and Machine Learning

## About
This project recognizes 10 different hand gestures using a webcam.

## Technologies
- Python
- OpenCV
- MediaPipe
- NumPy
- Scikit-learn
- Random Forest Classifier

## Gestures
1. Open Palm
2. Fist
3. Thumbs Up
4. Thumbs Down
5. Victory
6. Three Fingers
7. Four Fingers
8. OK Sign
9. Rock Sign
10. Call Me

## Project Workflow
1. Collect hand landmark data.
2. Train the Machine Learning model.
3. Recognize gestures using a live webcam.

## Run
python collect_data.py
python train_model.py
python live_gesture.py
